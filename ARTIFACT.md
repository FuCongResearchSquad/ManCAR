# ManCAR KDD 2026 Artifact

This repository contains the PyTorch reference implementation for the paper:

**ManCAR: Manifold-Constrained Latent Reasoning with Adaptive Test-Time Computation for Sequential Recommendation**

## Artifact scope

This artifact includes the source code, model implementation, training scripts, and instructions needed to run the ManCAR experiments.

## Code repository

https://github.com/FuCongResearchSquad/ManCAR

## Paper

https://arxiv.org/abs/2602.20093

## Dataset

The processed dataset referenced by this repository is available at:

https://huggingface.co/datasets/PIIR/ManCAR

## Environment

Please see `README.md` for package requirements. The key dependency is:

```text
torch==2.4.1
```

## Basic usage

```bash
cd ManCAR
bash ManCAR/run.sh
```
